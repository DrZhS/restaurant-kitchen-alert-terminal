# restaurant‑kitchen‑alert‑terminal
串行后厨智能备餐预警终端
> 🚧 **Project Status: Under Development | 开发中,以练习学习为主**

## 项目背景
为家庭串行做菜的餐饮门店开发备餐预警提醒系统。
门店已有打印机打印菜品小票，本系统不展示菜品，仅计算：当前订单预计出餐时间、后续队列预估等待时长，提供屏幕文字、LED灯光、语音备餐告警，缓解后厨卡餐问题。

## 系统架构
- **后端服务 Python Flask + SQLite**
承担全部业务逻辑：订单队列管理、串行排队计时、预估等待时间计算、告警判断；对外输出JSON接口。
- **硬件终端 ESP32**
最多设计3块PCB，包含屏幕主控板、按键声光板、可选电源板。
硬件只做HTTP获取JSON数据，屏幕显示、LED告警、喇叭提示。**硬件不实现业务逻辑。**

## 功能清单
1. 录入订单，标记普通外卖 / 大单 / 堂食
2. 强制串行约束：同一时间只能有1个订单处于制作中
3. 自动计算预计出餐时间、队列等待时长
4. 等待超时黄色/红色等级告警
5. ESP32屏幕展示时间信息，声光提醒
